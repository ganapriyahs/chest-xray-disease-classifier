# Chest X-Ray Disease Classifier

**[📄 Read the Full Project Paper](./PROJECT%20PAPER.pdf)**  

## Abstract
Approximately 2 billion chest X-rays are performed annually worldwide. Radiologists must interpret hundreds of these images per day, leading to fatigue and an increased risk of missed diagnoses. Missing a diagnosis is particularly dangerous for critical conditions such as Pneumonia, Pneumothorax, and Lung Mass.

A single chest X-ray commonly presents two or more concurrent pathologies, making traditional binary classification models inadequate for real-world clinical practice. This paper details the development of an AI-assisted multi-label triage tool capable of simultaneously detecting 14 different thoracic diseases from a single X-ray image to prioritize high-risk clinical cases.
